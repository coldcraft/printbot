02

Stack Components

SMS Gateway
TextBee
textbee.dev
Receives SMS, fires a webhook POST to your app with the message body and sender number.
App / API
PrintBot
Python (FastAPI) in Docker
Webhook receiver, orchestrator. Talks to Ollama, fetches URLs, builds print jobs, drives the printer.
Local LLM
Ollama
localhost:11434 — mistral / qwen2.5
Understands intent, routes message type, formats structured JSON back to the app. No cloud, no cost.
Printer Driver
python-escpos
ESC/POS protocol
Sends formatted commands to the thermal printer. Handles text, alignment, bold, cut, and image printing.
QR Codes
qrcode lib
pip install qrcode
Generates QR images from URLs, rendered directly onto the receipt alongside the summary.
Source Control
GitHub
Private repo
Dev PC pushes, Runner PC pulls. One script handles pull → rebuild → restart on the runner.
03

Features — Phased

Phase 1 — Core
📝 Reminders
SMS "reminder: take out the trash" → Ollama formats → prints with header, timestamp, tear off.
Phase 1 — Core
🌐 URL Summarizer
Send a URL → app fetches page → Ollama summarizes → prints summary + QR code of original URL.
Phase 1 — Core
🧠 Intent Routing
One system prompt handles all message types. Ollama returns JSON with type + formatted content.
Phase 2 — Expand
📋 Lists
"shopping list: milk, eggs, bread" → neatly formatted checklist receipt with boxes to tick.
Phase 2 — Expand
🗓️ Events / Calendar
Parse natural language dates and times, print as a mini event card with all details formatted.
Phase 2 — Expand
❓ Q&A
Ask a question, Ollama answers, prints the response. Like a receipt-sized knowledge card.
Phase 3 — Ideas
🌤️ Weather
Morning briefing triggered on schedule or by SMS. Prints day's forecast as a receipt.
Phase 3 — Ideas
📰 News Digest
Fetch headlines, summarize with Ollama, print a mini newspaper front page.
Phase 3 — Ideas
🔁 Scheduled Prints
Cron-style triggers — daily agenda, weekly review, habit tracker, whatever you want waking up on the printer.

Repo Structure (rough)

  Dockerfile
  app/
    main.py  ← FastAPI, webhook receiver
    router.py  ← calls Ollama, parses intent
    printer.py  ← ESC/POS formatting + print
    fetcher.py  ← URL scraping
    templates/  ← receipt layout per type
  prompts/
    system.txt  ← the main Ollama system prompt
  .env  ← TextBee keys, printer config
  deploy.sh  ← git pull + docker compose up on runner
